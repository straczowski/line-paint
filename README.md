# Line Paint

A browser drawing app in the spirit of [Excalidraw](https://excalidraw.com/), aimed at pen-plotter output.

Related: [line-weaver](https://github.com/straczowski/line-weaver/), which turns images into plotter-ready line drawings.

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

```bash
npm test
```
